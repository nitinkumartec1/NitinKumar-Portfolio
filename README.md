# Nitin Kumar — Developer Portfolio

Modern, high-performance portfolio website built with **Next.js 16 (Turbopack)**, **React 19**, and vanilla CSS design system.

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI & Architecture**: React 19, Vanilla CSS Design System
- **Typography**: Google Fonts (Syne, Instrument Serif, Inter, DM Mono)
- **Icons**: Lucide React & Custom SVG Monogram

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
